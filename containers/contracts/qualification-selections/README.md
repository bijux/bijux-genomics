# Qualification Source Selections

These declarations bind each tool qualification protocol to exact files in the admitted benchmark
data index. They contain no run state or scheduler identity. `bijux-dna-containers-qa` validates and
materializes them; the runner advances each valid selection independently.

The initial merge-pairs closure uses both mates from the same real, public horse WGS library and a
checksum-indexed 100,000-read prefix. This bounded corpus is suitable for container stage
qualification and interoperability checks; it is not publication evidence for whole-dataset
accuracy or population claims. Merge overlap and minimum-length parameters are held constant where
the native tool exposes those controls. Native commands that do not expose an equivalent control
retain an empty or reduced parameter projection rather than receiving a fabricated flag.

Every negative invocation names a deliberately absent first mate while retaining the admitted
second-mate path. A zero exit status therefore fails the qualification contract.

Declarations conform to
`containers/contracts/schemas/qualification-source-selection.v1.json`. Generated specification
sources and all raw attempt evidence belong under governed STUDY paths, never in this directory.
