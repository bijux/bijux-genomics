# GitHub Repository Evidence Archive

This directory governs the local archive of GitHub repositories referenced as
upstream evidence by `bijux-genomics`.

Only this contract and `MANIFEST.tsv` belong in the product repository. Mirror
and export locators use the logical `science/docs/` namespace and resolve below
the external sibling `bijux-genomics-science/` after removing that prefix.

[../README.md](../README.md) defines the broader upstream archive contract that
this GitHub-mirror surface complements.

## Canonical Targets

- [MANIFEST.tsv](MANIFEST.tsv)
  tracked repository target list and planned local paths; generated by
  `python3 makes/bin/sync_science_docs_github_repos.py --skip-sync`
- [mirrors/<owner>/<repo>.git](mirrors/<owner>/<repo>.git)
  untracked bare clone for the local archive
- [archives/<owner>--<repo>.tar.gz](archives/<owner>--<repo>.tar.gz)
  optional untracked compressed export generated on demand

## Sync Rule

Refresh this surface with:

```bash
python3 makes/bin/sync_science_docs_github_repos.py
```

Add `--archive-format tar.gz` when a compressed portable snapshot is required.
Use `--evidence-root PATH` or `BIJUX_SCIENCE_ARCHIVE_ROOT` to choose another
external archive. Payload paths inside the product checkout are rejected.

## Scope Boundary

This archive is for evidence-bearing upstream repositories, not general GitHub
infrastructure links such as package pages, workflow badges, pull requests, or
release status links.
