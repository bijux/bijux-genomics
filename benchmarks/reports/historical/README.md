# Historical benchmark reports

Reports in this directory preserve prior execution evidence but are not part of
the current admitted stage-report set. They must not be promoted into current
coverage or readiness without replaying the governed campaign and satisfying
the current source, parameter, interface, scheduler, and output contracts.

The run-2004 BAM mapping-summary report predates stage-interface and effective-
parameter evidence. Its measurements remain useful historical observations,
but it cannot truthfully claim the current normalized result and downstream
probe contract.
