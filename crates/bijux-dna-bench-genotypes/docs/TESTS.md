# Genotype benchmark contracts

Scientific and fixture contracts stay with their capability owners. The governed
VCF sample-cardinality parser assertion lives once under `bam::tests`;
`call::tests` retains its distinct call-stage matrix and BAM fixture binding.
Private assertions are compiled with the owner; public command behavior stays
in the CLI.

Additional cases reject declaration/adapter/parser/output drift before effects,
preserve an unowned report, and execute all five workflows twice using native local
tools. They verify retained native manifest paths, unchanged prior execution bytes,
unknown evidence preservation, stable output indexes and pseudohaploid replay.
Fixture copies are isolated per case and reuse the authored scientific corpus.

Qualify default and all-feature inventories, strict lint, dependency closure, public
consumer cases and policy boundaries on a frozen candidate. Local focused passes do
not establish complete workspace coverage or hosted Linux timing.

Private owner assertions live under `src/`: capability-local `tests.rs` modules and the crate-level `tests/` group. Existing `#[cfg(test)]` declarations compile each case exactly once in the owner library. Shared fixture support remains under `tests/support/`; no extra integration binary or production test API is required. Command integration tests stay with the CLI.
