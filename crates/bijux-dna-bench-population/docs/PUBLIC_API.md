# Population services

Each family exposes `run_local_vcf_<family>_smoke`, its persisted report contract,
and typed rows where applicable. `PopulationBenchmarkInputs` validates declaration
identity and multiplicity before effects. Services validate required bindings,
corpus identity and expected artifacts before execution.

PCA/admixture/population structure use supported bindings; ROH, IBD and demography
use governed templates. IBD also consumes explicitly scoped active readiness
observations. Acquiring declarations from other domains remains a composition concern.

## Ancestry and population-structure readiness

`readiness::{admixture, population_structure}` owns immutable evidence admission,
scientific assessment, native smoke orchestration and compatible report publication.
Services receive `PopulationBenchmarkInputs`, `VcfEvidenceSnapshot`, command publication
addresses and explicit repository/report paths. Stage/tool, corpus, asset, adapter,
parser and schema agreement is required before readiness locks or native effects.

The canonical `plink2` smoke remains stage-contract evidence. It is not execution
proof for each retained external backend. Coverage predicates, scientific population
policy, flat serialized fields and filesystem orchestration have separate owners
within each stage service. The governed report contract requires every retained backend to be complete.
Missing observations or smoke return failure and preserve the previous report;
malformed input agreement refuses before lock acquisition.

`ReadinessCommandPaths` re-exports the independent VCF evidence address record.
Publication addresses do not establish command readiness. The CLI acquires input
observations and presents the resulting report.

## PCA readiness evidence

PCA command and declared output projection lives in the VCF adapter evidence owner;
scientific assessment and report publication live in the population readiness owner.
`PcaAdapterEvidence` carries a full stage/tool/corpus/asset binding, adapter/parser/schema
identity, structured command and declared output addresses through the independent
VCF evidence crate. Publication addresses are not executed scientific proof.

Population readiness checks immutable snapshot agreement before readiness locks and
native smoke execution. Adapter acquisition rejects ambiguous retained declarations
before materialization. The CLI shares one admitted adapter observation context across
common evidence and PCA projection. Script and argv publication retain their existing
paths and representations; both serialize before either file is written.
