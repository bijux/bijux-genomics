# Scientific completion contracts

`ProofContext` supplies the repository, `ReadinessEvidence` and `NativeProofWriter`.
The public stage modules expose their original row/report records, embedded normalized
metrics and render operations. Serialized names and schema identities are unchanged.
Scientific summaries use canonical `bijux-dna-domain-bam` types; the owner does not create
replacement wire schemas for those records.

Providers return acquisition errors directly; no fallback source or substituted native
operation is selected. The owner reads referenced evidence, checks retained scientific
conditions, publishes complete or incomplete reports, and returns an error for incomplete
coverage. Existing generic JSON presence checks and path-existence limitations remain
visible; they are not promoted into stronger scientific guarantees.
