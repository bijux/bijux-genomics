# Binding evidence tests

Owner tests inject small declaration observations to test selection, label precedence,
duplicate admission, missing fields, completeness, exact output roles, explicit paths,
source acquisition counts and retained report bytes after rejection. These are engineering
contracts, not synthetic claims about scientific tool performance.

Existing CLI cases retain canonical catalog/planner acquisition and all original assertions.
Default/all-feature native test identities and strict lint qualify affected behavior.
Native Cargo metadata verifies the independent normal/dev dependency closure. Focused
qualification does not establish full workspace or hosted CI timing completion.
