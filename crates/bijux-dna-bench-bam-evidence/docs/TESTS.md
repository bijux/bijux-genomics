# BAM evidence tests

The owner suite covers gap precedence, parser exclusions, missing adapters, planner
diagnostics, explicit output templates, exact report identity, request acquisition
counts, fresh observations, explicit-root publication, binding drift and duplicate
active rows. Small injected records describe declarations; they are not native BAM
fixtures or scientific performance evidence.

Original CLI contract assertions retain real canonical catalog, planner and report
composition. Native Cargo metadata and the workspace dependency graph verify the
independent normal/dev closure. Default and all-feature identities are compared;
passing a focused suite does not qualify the full workspace or hosted CI duration.

## Readiness admission

Private owner tests cover retained binding and schema admission, duplicate binding
and report-binding rejection, actual JSON read/parse source identity, declaration
admission before document reads, ordered/repeated proof addresses, and the existing
difference between strict file and legacy path admission. Six public owner regressions
reject declaration input before native effects while preserving the previous report.

Canonical CLI JSON/file cases and the original six private readiness cases retain
positive coverage for all families, with default and `bam_downstream` feature
inventories checked separately. Synthetic admission cases establish engineering
boundaries; they do not stand in for native execution or scientific equivalence.
