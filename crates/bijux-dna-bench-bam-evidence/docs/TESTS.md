# BAM evidence tests

The owner suite covers gap precedence, parser exclusions, missing adapters, planner
diagnostics, explicit output templates, exact report identity, request acquisition
counts, fresh observations, explicit-root publication, binding drift and duplicate
active rows. Small injected records describe declarations; they are not native BAM
fixtures or scientific performance evidence.

Original CLI contract assertions retain real canonical catalog, planner and report
composition. Native Cargo metadata and the workspace dependency graph verify the
independent normal/dev closure. Default and all-feature identities are compared;
passing a focused suite does not qualify the full workspace or hosted CI duration.
