# bijux-dna-bench-vcf-evidence

Pure VCF benchmark evidence contracts, semantic admission and command projections.

## Ownership

`model` owns the existing VCF scope, adapter-output, parser-fixture, command,
expected-result and report wire records. `snapshot` rejects ambiguous identities
and contradictory joins, then provides reusable stage observations. `commands`
validates structured argv against shell projections and explicit pipe dependencies.

## Boundaries

The crate does not acquire files, execute processes, or depend on CLI, execution,
corpus or other workspace crates. Acquisition adapters supply observations; callers
own publication effects and write the returned projections. Missing evidence remains visible. Admitted declarations and
fixture coverage do not certify execution or scientific interchangeability.
