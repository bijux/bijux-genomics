# Evidence boundary tests

The contracts target uses in-memory observations and requires no external tools or
repository fixture checkout. Tests exercise all seven duplicate authorities, full
corpus-specific parser identity, active/parser/schema disagreement, unknown/foreign
bindings, report and fixture-count contradictions, incomplete evidence, deterministic
selection and reuse. Command tests cover shell-sensitive and empty arguments,
duplicate steps, NUL refusal, pipeline topology and shell/argv disagreement.

Existing public command tests retain the governed repository data, report schemas
and native workflow composition coverage. Those integration observations qualify
acquisition consumers separately from this pure evidence contract.
